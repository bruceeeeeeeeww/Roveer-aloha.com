# 羅浮音樂會 ALOHA 人氣票選｜V1.4 管理員版

管理 PIN：`34570`

## 這版新增
- 首頁低調的「⚙️ 管理員」入口
- 管理 PIN 由 Apps Script 後端驗證
- 管理員即時查看排名與票數
- 顯示：已投票數 / 未使用投票碼 / 總投票碼 / 候選人數
- 管理員可「關閉投票」與「重新開放投票」

- 保留原本投票碼一次性驗證、LockService 防重複投票

## 重要：你需要更新兩邊

### A. Apps Script
1. 打開原本 Apps Script 專案。
2. 把 `apps-script/Code.gs` 內容完整覆蓋原本 Code.gs。
3. 儲存。
4. 手動執行 `initializeSystem()` 一次。
   - 會在「系統設定」加入 `管理PIN / 34570`
   - 不會刪除既有投票紀錄或投票碼。
5. 「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。
   - 一定要建立新版本，否則 `/exec` 還是舊程式。

### B. GitHub Pages
將 repository 根目錄更新為：
- index.html
- admin.html
- style.css
- app.js
- favicon.svg

`apps-script` 資料夾不需要上傳 GitHub Pages；它只提供你複製 Code.gs。

## 測試順序
1. 首頁一般投票正常。
2. 點頁尾「⚙️ 管理員」。
3. PIN 輸入 `34570`。
4. 能看到票數與排名。
5. 按「關閉投票」。
6. 用一組未使用投票碼測試，應顯示目前投票已截止。
7. 管理員再按「重新開放投票」。

## 安全提醒
`34570` 是 5 位數 PIN，活動型用途可以使用，但防猜測能力有限。
管理頁不會把 PIN 寫在公開前端原始碼；PIN 實際值存放於 Google Sheet 的「系統設定」並由 Apps Script 比對。
